Free Sudoku Game

Fill every row, column, and 3 × 3 box with the numbers 1 to 9. Each number must appear only once in each row, column, and box.

Select a square, then choose a number.

How to play Sudoku

  1. Select an empty square on the board.
  2. Choose a number from 1 to 9.
  3. Do not repeat a number in the same row, column, or 3 × 3 box.
  4. Click Check Answers to check your progress.
