What is URL encoding?

URL encoding represents certain characters using percent signs and hexadecimal values. It is commonly used when data needs to be included in a URL query parameter.

Component encoding vs. full URI encoding

Use Encode Component for individual values, such as a search query. Use Encode Full URI when you need to preserve URI structure characters such as slashes and colons.

Only decode text from sources you trust. Decoded content may contain links or text that you should inspect before using.
