What is a JSON formatter?

JSON is a common data format used by APIs, web applications and software configuration files. A JSON formatter adds indentation and line breaks to make structured data easier to read.

How to use this tool

  1. Paste your JSON into the input box.
  2. Choose your preferred indentation.
  3. Click Format JSON to check and format your data.
  4. Copy the result or download it as a JSON file.
