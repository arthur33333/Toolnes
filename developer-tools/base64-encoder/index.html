What is Base64?

Base64 is a way to represent binary data as text using a limited set of characters. It is commonly used in data transmission and encoding binary content for text-based formats.

How to use this tool

  1. Enter your text or Base64 string.
  2. Choose Encode to Base64 or Decode from Base64.
  3. Copy the result or download it as a text file.

Base64 is encoding, not encryption. It does not protect passwords, API keys or confidential information.
