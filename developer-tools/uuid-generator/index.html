What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit identifier commonly used to identify records, resources, sessions and objects in software. UUID version 4 uses randomly generated values.

How to use this generator

  1. Choose how many UUIDs you need, from 1 to 1,000.
  2. Select lowercase or uppercase letters.
  3. Click Generate UUIDs.
  4. Copy the results or download them as a text file.

UUIDs are designed to make collisions extremely unlikely, but they should not be treated as a substitute for secure authentication tokens or access-control systems.
