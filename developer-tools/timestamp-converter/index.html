What is a Unix timestamp?

A Unix timestamp is a numeric representation of a point in time. It is widely used in software, databases, APIs, and log files. Unix timestamps are conventionally based on UTC, so the same timestamp represents the same instant around the world.

Seconds vs. milliseconds

  • Seconds: commonly a 10-digit number, such as 1700000000.
  • Milliseconds: commonly a 13-digit number, such as 1700000000000.
