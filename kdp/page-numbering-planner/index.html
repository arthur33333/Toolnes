Frequently asked questions

Does this tool add numbers to my PDF?

No. It creates a pagination plan and a sample preview. Use a word processor or PDF editing tool to apply actual page numbers.

Should front matter use Roman numerals?

Some books use lowercase Roman numerals for preliminary pages, while others hide visible numbers. Choose the style that fits your book design.

Does the first chapter have to display page number 1?

Not necessarily. You can plan to hide the number on the first main-text page while keeping it in the numbering sequence.

Is this an official KDP tool?

No. This is an independent planning utility. Check current publishing specifications and inspect your exported interior before uploading.
