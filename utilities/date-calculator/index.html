How to Use the Date Calculator

  • Enter a start date, choose the operation and set the amount and unit.
  • Choose Date Difference to calculate the number of days between two dates.

About Date Calculations

This tool uses calendar dates. Months and years are calculated as calendar units rather than fixed numbers of days. If the target month has fewer days, the result uses the last valid day of that month.
