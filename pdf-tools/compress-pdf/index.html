Compress PDF Online

Try to reduce your PDF file size with this free browser-based tool. Select a PDF and choose an optimization option to create a new file.

Note: this tool removes some unnecessary PDF structure where possible. It does not re-encode embedded images, so the file may not always become smaller.

How to optimize a PDF

  1. Select a PDF from your device.
  2. Choose an optimization option.
  3. Click Optimize PDF.
  4. Compare the original and new file sizes, then download the result.

Does this always reduce file size?

No. PDF size depends on its images, fonts, and internal structure. This tool attempts to save the document in an optimized form, but some files may remain the same size or become slightly larger. For stronger image compression, a tool that re-encodes embedded images is needed.
