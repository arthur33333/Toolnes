Add Page Numbers to PDF

Add page numbers to your PDF in seconds. Choose the position, starting number, and numbering format, then download the updated document.

How to number PDF pages

  1. Select your PDF file.
  2. Choose where the numbers should appear.
  3. Select a numbering format and starting number.
  4. Click Add Page Numbers and download the result.

Free online PDF page numbering

This tool adds numbers to every page of a PDF. The original file remains unchanged. Page numbers are placed over the existing page content near the selected edge.
