How to convert Base64 to an image

  1. Paste a Base64 string or a data URL into the text box.
  2. Click Convert to Image.
  3. Preview the image if the data is valid.
  4. Click Download Image to save it.

What is a data URL?

A data URL contains a media type and encoded data, usually in a format such as data:image/png;base64,.... This tool checks that the content is an image before displaying it.

Privacy: The conversion happens in your browser. The pasted data is not sent to a Toolnes server.
