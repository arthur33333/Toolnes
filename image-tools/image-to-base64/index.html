What is Base64?

Base64 represents binary data as text. Developers sometimes use it to embed small images in HTML or CSS, or to pass image data through systems that accept text.

How to convert an image to Base64

  1. Select an image from your device.
  2. Click Convert to Base64.
  3. Choose whether to include the data URL prefix.
  4. Copy the result or download it as a TXT file.

Note: Base64 output is usually larger than the original binary image. Very long strings can be inconvenient to use in web pages. The conversion runs locally in your browser.
